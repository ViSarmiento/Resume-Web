## Project Description

This is a personal portfolio/resume website designed to showcase my professional profile as an IT student. The page presents my educational background, technical skills, work experience, hobbies, and contact information in a clean, modern layout. The design features a hero section with a circular profile photo that creatively breaks out of its container, creating a visually striking effect.

The website serves as a digital resume that can be easily shared with potential employers, colleagues, or peers. It emphasizes clarity, efficiency, and a professional yet approachable aesthetic.

---

## Features of the Website

- **Responsive Layout** – Adapts seamlessly to different screen sizes (desktop, tablet, mobile)
- **Two-Column Grid Layout** – Organizes information into left (education, experience, skills) and right (hobbies, contact, social links) columns
- **Interactive Skill Tags** – Skills have a hover effect that changes their appearance
- **Quote Section** – Features a personal motto
- **Contact Information** – Includes email, phone number, and location with clickable links
- **Social Media Links** – Placeholder links for GitHub, LinkedIn
- **Gradient Color Scheme** – Uses purple gradients for a cohesive, modern visual identity
- **Clean Typography** – Uses system fonts for fast loading and readability

---

## Technologies Used

- **HTML5** – Semantic markup for structure and content
- **CSS3** – Custom styling with:
  - Flexbox and Grid for layout
  - CSS gradients for backgrounds
  - CSS transitions and hover effects
  - Responsive design with media queries
  - `overflow: hidden` technique for the breaking-out circle effect
